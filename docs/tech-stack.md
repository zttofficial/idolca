# 技術選型

## 產品定位

K-pop 小卡的鏈上倉儲交易平台：實物入庫鑑定，每張卡在 Solana 上對應一個 NFT；成交時卡留在倉庫，NFT 在鏈上轉移；持有人隨時可以銷毀 NFT，換取實物寄出。價格以 USDT 計價和結算。

用戶有兩種登入方式，登入框裡並列，互不衝突：
- **加密用戶**：用 Phantom、Solflare、Backpack 等瀏覽器錢包簽名登入，上鏈的卡直接進自己的錢包。
- **粉絲**：用郵箱和密碼註冊，不需要錢包；上鏈的卡由平台錢包代管，不用懂助記詞和 Gas。

這樣首頁和產品都是 Web3 的，但不把不懂加密的粉絲擋在門外。

## Web3

| 層 | 選擇 | 理由 |
|---|---|---|
| 鏈 | **Solana** | 卡牌 RWA 的主戰場（約 63% 的代幣化卡牌交易在 Solana）；Magic Eden、Tensor、Jupiter 都能直接交易；手續費不到 1 美分 |
| 帳號 | 自建：郵箱 + 密碼，或錢包簽名 | 帳號存在自己的資料庫，不依賴第三方登入服務。密碼用 Node 內建 scrypt 加鹽雜湊；錢包登入是 Sign In With Solana 的簡化版：伺服器發一段帶一次性隨機數的訊息（5 分鐘有效、用過即作廢），錢包簽名後伺服器用 ed25519 驗簽，地址第一次出現就建帳號。兩種方式都換成同一種會話：令牌放 httpOnly cookie，資料庫只存它的 SHA-256。Google、Apple 登入和郵箱驗證暫不做 |
| 錢包 | Wallet Standard（`@wallet-standard/app`） | 直接偵測瀏覽器裡的 Phantom、Solflare、Backpack 等 Solana 錢包，不經過第三方連接服務。郵箱帳號的卡由平台錢包代管，之後提供提領到自己錢包的功能 |
| 卡片 NFT | **Metaplex Core**，金庫卡和自由上鏈的收藏卡各一個集合，都帶平台可改的 `verification` 鑑定狀態。收藏卡量大後改用 Bubblegum v2 壓縮 NFT 降低成本 | 一張卡一個帳戶，鑄造成本約 0.003 SOL；Attributes 插件存屬性（編號、團體、成員、專輯、版本、類型、評級、庫位、入庫日期），FreezeDelegate、BurnDelegate 插件管提貨，集合上的 Royalties 插件收二級市場版稅 |
| 計價與結算 | **USDT（SPL）**，同時接受 USDC | 前台一律顯示 USDT，懸停時按瀏覽器語言顯示當地貨幣參考價（₩、¥、CN¥、NT$、HK$、฿、Rp、₫）；devnet 沒有官方 USDT，用 Circle 的 devnet USDC 或自鑄測試幣代替 |
| 鏈上程序 | Anchor 1.x（Rust） | 自寫一個最小的掛單託管程序：賣家掛單時 NFT 轉進以資產地址為種子的 PDA，買家付款後原子交換，平台抽成在同一筆交易內扣除；只接受平台集合的資產和 USDT、USDC，抽成上限 10% |
| 鏈上數據讀取 | Helius RPC + DAS API | 查詢集合裡的卡、錢包持有的卡；Webhook 監聽託管程序的掛單、成交、取消事件，同步到資料庫 |
| 可驗證隨機數 | Switchboard VRF（主網） | 盲盒卡包的抽卡隨機數，結果可公開驗證；devnet 階段由伺服器用加密隨機數抽 |

### 鏈上流程

| 動作 | 鏈上發生什麼 |
|---|---|
| 入庫 | 鑑定通過後，平台給寄存人鑄造一個 Core NFT，屬性寫入編號和卡片資料 |
| 掛單、成交 | NFT 進託管程序；買家付 USDT，NFT 和款項在同一筆交易裡交換；取消掛單時 NFT 退回賣家 |
| 外部交易 | Core NFT 可以在 Magic Eden、Tensor 直接買賣，不經過平台 |
| 提貨 | 持有人簽名申請：把凍結權和銷毀權委託給平台並立即凍結，之後不能轉手或掛單。寄出時平台在同一筆交易裡解凍並銷毀，倉庫記錄同步下架。取消申請時平台解凍 |
| 開盲盒 | 買家付 USDT 進平台錢包；平台對帳後從卡池不放回地抽卡，把抽到的卡鑄成金庫 NFT 給買家。主網把卡池清單的哈希開賣前上鏈承諾，抽卡改用 VRF |
| 即時回購 | 平台按卡片價值的 70% 付 USDT：持有人把 NFT 轉給平台、平台付款，兩步在同一筆交易裡（平台先簽付款，持有人簽轉移） |

### 存貨證明

- 公開的金庫頁（`/vault`）：列出每個編號對應的 NFT 地址、持有人、狀態（在庫、掛單中、提貨中）、入庫日期和最近一次盤點時間；點編號進卡片頁看正反面照片。
- 未銷毀的 NFT 總數必須等於倉庫實物數量：提貨中的卡還在倉庫裡，NFT 凍結但未銷毀；寄出時才銷毀。定期公布盤點結果。
- 平台不持有永久凍結權或永久銷毀權，只有持有人主動申請提貨時才臨時委託給平台。

### 不做

- **不發平台代幣。** 代幣會讓產品被看成炒幣，加重粉絲反感和監管風險；先證明交易本身成立。
- **只給入庫估值 10 USDT 以上的卡鑄造 NFT。** 更便宜的卡留在倉庫內部帳本，避免鑄造和託管成本超過卡價。

## 市場瀏覽

- 參考兩個競品：KOCA 主打「切換藝人與角色」，Pocamarket 的篩選是價格、類型、隱藏缺貨，排序預設熱門。
- 金庫卡和自由刊登分兩個頁籤（見「兩條交易線」）；自由刊登搜尋標題、團體、成員、專輯、版本，篩選團體和價格，排序按最新刊登和價格。
- 市場頁（`/market`）：關鍵字搜尋（團體、成員、專輯、版本、編號，多個詞全部命中）、團體 → 成員兩層切換（選項旁顯示數量）、類型、價格區間、只看在售、排序（熱門、最新入庫、價格高低）、每頁 12 張分頁。篩選狀態全部寫在網址查詢字串裡，可以分享，也能用瀏覽器返回。
- 導航列的搜尋框送到市場頁；首頁只放 24h 漲幅前 8 張和「看全部」入口，類型標籤直接連到篩選好的市場頁。
- 金庫頁按狀態分頁籤並可搜尋；圖鑑團體頁可按成員、類型篩選，並搜尋版本名稱。
- 現在的樣本只有十幾張，篩選在瀏覽器端完成；卡片多了之後改成伺服器端查詢資料庫，網址參數格式不變。

## 圖鑑與收藏冊

- 不交易的粉絲也有理由每天來：圖鑑收錄每個卡款（團體 × 專輯 × 成員 × 版本），可以標記「有」和「想要」，旁邊顯示在售數量和最低價；收藏冊照實體卡冊做成 3×3 卡位、雙頁攤開，附收集進度和想要清單。逛圖鑑、記收藏冊不需要登入，登入後收藏冊存進帳號。
- **自由上鏈**：用戶拍下卡片正反面（都必填，背面能看出版本和真偽線索），可以再補最多 6 張照片（一組卡的合照、卡角細節）；選來源、填團體和成員，標題、張數、出處名稱、版本選填，就能鑄造成收藏 NFT。一則可以是一張卡，也可以是一組卡，學 KOCA 和粉絲在社群裡出卡的習慣。來源不只專輯：專輯、預購特典、幸運抽、簽售和視訊簽售、演唱會和見面會周邊、年曆、官方粉絲俱樂部禮包、快閃店、音樂節目和活動、品牌合作、其他。卡款不必在圖鑑裡，圖鑑只提供輸入建議；單張卡的名稱和圖鑑完全一致時自動關聯卡款。鑄造需要登入。
- 用戶路徑：記錄收藏 → 自由上鏈 → 自由刊登，或寄卡入庫鑑定後走金庫交易。

## 兩條交易線

市場分成兩條線，對應 Pocamarket 的 Official 和 Used：

| | 金庫卡（`/card/[id]`） | 自由刊登（`/listing/[id]`） |
|---|---|---|
| 卡在哪 | Idolca 金庫 | 賣家手上 |
| 誰查驗 | Idolca 入庫時實物鑑定，通過才鑄造 | 沒人查驗，買家看到免責聲明 |
| NFT | 金庫集合的 Core NFT，`verification: authentic` | 收藏集合的壓縮 NFT，`verification: unverified` |
| 成交 | 鏈上託管程序原子交換，卡不動 | 擔保交易：買家付 USDT 進平台錢包，賣家寄卡，買家確認收貨後平台放款並用 PermanentTransferDelegate 把 NFT 轉給買家 |
| 提貨 | 銷毀 NFT 換實物 | 不適用，卡本來就在持有人手上 |

- 自由刊登就是給收藏 NFT 標價：可以在上鏈時直接刊登，也可以之後在收藏冊裡刊登、改價、下架。
- 市場頁用頁籤切換兩條線，網址參數 `lane=free`；自由刊登頁籤頂部和商品頁價格旁都放免責聲明。自由刊登的卡用賣家照片和「待驗證」標籤顯示，不加全息效果，和金庫卡一眼分得出來。

### 卡片 NFT 的鑑定狀態

兩條線是兩碼事，鑑定狀態也分開，只有平台能改，持有人改不了：

| 狀態 | 屬於 | 含義 |
|---|---|---|
| `unverified`（待驗證） | 收藏 NFT | 自由上鏈的卡一律是這個狀態，平台不查驗 |
| `fake`（假卡） | 收藏 NFT | 被檢舉或寄到金庫後查出是假卡；同時下架，之後不能再刊登 |
| `authentic`（真品） | 金庫 NFT | 金庫入庫鑑定通過才鑄造，所以金庫 NFT 一律是真品 |

- **收藏 NFT**：鑄造到獨立的「Idolca Collector」Core 集合，手續費由平台代付。錢包登入的用戶鑄到自己的錢包，郵箱帳號鑄到平台代管錢包。平台是集合的更新權限持有人，可以改寫名稱和屬性。屬性（Attributes 插件）：團體、成員、來源、張數、出處名稱、版本、`custody: self`、`verification`；元數據 JSON 由 `/api/meta/item/{id}` 提供，含所有照片。每個 NFT 自帶 PermanentFreezeDelegate 插件，平台可以單獨凍結假卡；集合帶 PermanentTransferDelegate 插件，自由刊登成交時由平台把 NFT 轉給買家。
- **寄進金庫**：收藏 NFT 的卡寄到金庫鑑定為真後，銷毀收藏 NFT，在金庫集合鑄造金庫 NFT。查出是假卡則退回卡片，收藏 NFT 改成假卡。
- **標記假卡**：收藏 NFT 不銷毀。平台在同一筆交易裡把名稱改成「[FAKE] …」、屬性改成 `verification: fake`，並凍結 NFT，防止它被當作真卡轉賣；元數據 JSON 也同步顯示假卡說明，任何外部市場和錢包都看得到。標記不可由持有人移除，平台也不會在鏈上撤銷。
- 金庫的託管合約只接受金庫集合的資產，收藏 NFT 在鏈上就無法走金庫交易。
- 鑄造和標假卡都在 Solana devnet 真實執行（見「devnet 部署」）。紀錄、刊登價格、NFT 地址和交易簽名存進 `collector_items` 表，照片存進 `media` 表；標記假卡透過管理接口 `PATCH /api/admin/items/{id}` 觸發（用 `ADMIN_TOKEN` 保護）。沒有平台金鑰的環境退回演示模式：NFT 地址是隨機字串，介面不顯示 Solscan 連結。

## 專輯銷量榜單

- Pocamarket 和 KOCA 都沒有專輯銷量榜，這是差異化功能。目前是看板展示（`/charts`）：週榜（本週銷量、累計、在榜週數、排名變化）和初動榜（發行後 7 天銷量），附 Hanteo 和 Circle 的統計口徑說明。
- 數據是樣本：專輯是真實發行的，銷量是示意的。正式版需要授權的榜單數據，按週更新。
- 之後接「代購代拆」：用戶在 Idolca 預購專輯，平台向 Hanteo 加盟店購買並在首爾開封，小卡入庫，專輯計入榜單銷量；上線前要先和 Hanteo 確認這種模式是否計入。

## 盲盒卡包（Mystery Pack）

- 參考 Pocamarket 的 Mystery Pack：低價買一包，有機會抽中高價卡；卡池有限，賣完提前結束；有即時抽卡播報。
- 卡分 SSR、SR、R、N 四級。機率不單獨設定，等於「該級剩餘張數 ÷ 卡池剩餘總數」，所以隨賣出即時變化，頁面公開每級剩餘張數、價值區間和單包期望價值。
- 一次可開 1、5、10 包：撕開卡包，逐張翻卡，SSR 有金色光圈。抽到的卡以 NFT 進錢包，可以留在金庫、上架、即時回購或提貨。
- 開包是真實的 devnet 交易：用錢包付測試 USDT，伺服器對帳後抽卡並鑄造；卡池剩餘張數扣掉所有人已開出的。結果頁每張卡可以留著或即時賣回。鏈上未配置的環境退回瀏覽器本地演示。

## 錢包交易流程

所有需要用戶簽名的動作都是同一個模式：伺服器組好交易（手續費付款人是用戶錢包，需要平台參與的部分由平台先簽）→ 瀏覽器錢包用 Wallet Standard 的 `solana:signAndSendTransaction` 簽名送出 → 伺服器等交易確認、更新狀態。前端不載入 Anchor，也不接觸平台金鑰。

| 流程 | 用戶簽什麼 | 平台做什麼 |
|---|---|---|
| 買金庫卡 | 託管程序的 `buy`：USDT 付給賣家和平台抽成，NFT 轉給買家 | — |
| 掛單、取消 | 託管程序的 `list` / `cancel` | — |
| 申請提貨 | 把銷毀權委託給平台，並以平台為凍結代理凍結 NFT | 後台出貨時在同一筆交易裡解凍並銷毀 |
| 自由刊登購買 | 把 USDT 轉進平台錢包，備註寫訂單編號 | 按備註和金額對帳；買家確認收貨後放款給賣家（扣 2.5%），NFT 轉給買家；賣家沒綁錢包時貨款先暫存，綁定後補發；同一件商品被兩人同時付款時，後到的自動退款 |
| 開卡包 | 把 USDT 轉進平台錢包，備註寫訂單編號 | 對帳後抽卡、把抽到的卡鑄成 NFT 給買家 |
| 即時回購 | 把 NFT 轉給平台 | 同一筆交易裡付 USDT（平台先簽） |

- **錢包綁定**：郵箱帳號可以在帳號選單裡綁定錢包（同樣是簽一段文字證明持有），之後買賣都用這個錢包；錢包登入的帳號本身就有錢包。
- **測試幣**：devnet 上帳號選單提供一鍵領取 0.02 SOL 和 500 測試 USDT（平台是測試 USDT 的鑄幣權限持有人），每個帳號 10 分鐘一次。
- **鏈上即時狀態**：金庫卡的持有人、掛單價格、是否提貨中直接讀鏈（一次批量讀資產和掛單帳戶，伺服器快取 10 秒），市場、金庫頁、卡片頁和收藏冊都以它為準；已提貨銷毀的卡移出金庫和市場。
- **後台**：`/admin` 用 `ADMIN_TOKEN` 解鎖，處理提貨出貨和標記假卡。

## 合規要點

- 盲盒卡包和回購有賭博屬性：機率按卡池剩餘張數即時公開，同時公開單包期望價值；限 18 歲以上，按地區屏蔽；已開的卡包不退款。
- USDT 出入金涉及反洗錢：提現到外部錢包超過一定金額時做 KYC。
- 偶像肖像有 IP 風險：上線後 NFT 和卡片頁只用入庫實物的掃描圖，不拿偶像照片做營銷素材。展示站的樣本卡用 CC BY 授權照片，在 `/credits` 頁署名，不用於廣告投放。

## 卡面圖片

- 沒有實拍圖的卡，卡面由 `src/lib/card-art.ts` 用 canvas 生成佔位圖。
- 卡片資料帶 `image` 時，3D 卡和列表卡改用實拍圖，載入失敗退回佔位圖。入庫後填入正反面掃描圖即可，渲染代碼不用改。
- 所有照片走同一條處理流程（`src/lib/server/media.ts`）：伺服器端驗證確實是圖片，裁成 55:85、660×1020 的 JPEG，存兩份——未加浮水印的原圖留給鑑定，加了浮水印的展示圖對外提供。上傳的一組正反面只要有一張不合格就整組拒絕。
- 浮水印學 Pocamarket：半透明的白色 idolca 文字標誌斜 30° 平鋪滿整張圖，帶極淡的黑色描影，深淺背景上都看得見；裁掉一角也去不掉。正反面用同一套處理，和平台統一卡背的平鋪標誌一致。標誌用字形輪廓繪製，不依賴伺服器上的字型。
- 樣本卡照片是維基共享資源上 CC BY 授權的偶像照片，倉庫裡只記來源網址和裁切位置（`src/lib/sample-credits.json`）。某張樣本照第一次被請求時，伺服器從維基共享資源抓圖，走上面的流程入庫，之後直接從資料庫讀。圖片按網址長期快取，所以樣本照的 id 帶處理版本號（`src/lib/sample-image.ts` 的 `SAMPLE_REV`）：裁切或浮水印一改就把版本號加一，伺服器重新生成，瀏覽器和 CDN 也不會繼續用舊圖。作者和授權由 `/credits` 頁公開署名。
