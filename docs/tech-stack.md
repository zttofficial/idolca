# 技術選型

## 產品定位

K-pop 小卡的鏈上倉儲交易平台：實物入庫鑑定，每張卡在 Solana 上對應一個 NFT；成交時卡留在倉庫，NFT 在鏈上轉移；持有人隨時可以銷毀 NFT，換取實物寄出。價格以 USDT 計價和結算。

用戶有兩種進入方式：
- **加密用戶**：直接連 Phantom、Solflare、Backpack 等錢包。
- **粉絲**：用郵箱或 Google、Apple 登入，系統自動生成一個內嵌錢包，不用懂助記詞和 Gas。

這樣首頁和產品都是 Web3 的，但不把不懂加密的粉絲擋在門外。

## 前端

| 層 | 選擇 | 理由 |
|---|---|---|
| 框架 | Next.js 16（App Router）+ React 19 + TypeScript | 市場頁和卡片頁需要 SSR 和 SEO |
| 樣式 | Tailwind CSS v4 | 白底電商風格，參考 Pocamarket：顏色只用語義變數（三級文字、三級底色、邊線、一個主色 `#e8285a`、漲跌、提示），按鈕用純色不用漸變；卡片照片是畫面裡最鮮豔的元素，全息效果只留在卡片上。標誌是扁平文字標誌：小寫粗體「idolca」，i 的點是一張斜放的主色小卡，不用圖示框和漸變。所有頁面（包括盲盒頁）都用同一套淺色變數，只有開盲盒的全屏動畫在 `.theme-dark` 範圍內換成中性黑 |
| 3D 卡片 | three.js + React Three Fiber + drei | 首頁主視覺：可拖動旋轉、翻到背面的小卡 |
| 全息效果 | 自寫的 GLSL shader（3D 卡）、CSS 混合模式（列表卡） | 3D 卡只有一張，用 WebGL；列表卡很多，用純 CSS 保證性能 |
| 多語言 | next-intl | 首發英文、繁中、簡中、日文、韓文、泰文、印尼文、越南文；英文是默認語言，網址不帶前綴，其他語言帶前綴（`/zh-Hant/vault`）；不按瀏覽器語言自動跳轉，由用戶在語言選單切換；品牌名 Idolca 不翻譯 |

## Web3

| 層 | 選擇 | 理由 |
|---|---|---|
| 鏈 | **Solana** | 卡牌 RWA 的主戰場（約 63% 的代幣化卡牌交易在 Solana）；Magic Eden、Tensor、Jupiter 都能直接交易；手續費不到 1 美分 |
| 帳號 | 自建：郵箱 + 密碼 | 帳號存在自己的資料庫，不依賴第三方登入服務；密碼用 Node 內建 scrypt 加鹽雜湊，會話令牌放 httpOnly cookie、資料庫只存它的 SHA-256。逛圖鑑、記收藏冊只需要帳號，不需要錢包。Google、Apple 登入和郵箱驗證暫不做 |
| 收藏錢包 | **Privy**（延後引入） | 用戶第一次交易或上鏈時才建立 Solana 內嵌錢包，介面上叫「收藏錢包」，不出現助記詞；這樣平台不託管私鑰，也不用申請託管牌照。免費方案約 500 月活，付費每月 299 美元起 |
| 外部錢包 | Wallet Standard（Privy 內建連接器） | Phantom、Solflare、Backpack 及瀏覽器裡偵測到的其他 Solana 錢包 |
| 卡片 NFT | **Metaplex Core**（金庫卡）、Bubblegum v2 壓縮 NFT（自述收藏），都帶平台可改的 `verification` 鑑定狀態 | 一張卡一個帳戶，鑄造成本約 0.003 SOL；Attributes 插件存屬性（編號、團體、成員、專輯、版本、類型、評級、庫位、入庫日期），FreezeDelegate、BurnDelegate 插件管提貨，集合上的 Royalties 插件收二級市場版稅 |
| 計價與結算 | **USDT（SPL）**，同時接受 USDC | 前台一律顯示 USDT，懸停時按瀏覽器語言顯示當地貨幣參考價（₩、¥、CN¥、NT$、HK$、฿、Rp、₫）；devnet 沒有官方 USDT，用 Circle 的 devnet USDC 或自鑄測試幣代替 |
| 鏈上程序 | Anchor 1.x（Rust） | 自寫一個最小的掛單託管程序：賣家掛單時 NFT 轉進以資產地址為種子的 PDA，買家付款後原子交換，平台抽成在同一筆交易內扣除；只接受平台集合的資產和 USDT、USDC，抽成上限 10% |
| 鏈上數據讀取 | Helius RPC + DAS API | 查詢集合裡的卡、錢包持有的卡；Webhook 監聽託管程序的掛單、成交、取消事件，同步到資料庫 |
| 可驗證隨機數 | Switchboard VRF | 盲盒卡包（第二階段）的抽卡隨機數，結果可公開驗證 |

### 鏈上流程

| 動作 | 鏈上發生什麼 |
|---|---|
| 入庫 | 鑑定通過後，平台給寄存人鑄造一個 Core NFT，屬性寫入編號和卡片資料 |
| 掛單、成交 | NFT 進託管程序；買家付 USDT，NFT 和款項在同一筆交易裡交換；取消掛單時 NFT 退回賣家 |
| 外部交易 | Core NFT 可以在 Magic Eden、Tensor 直接買賣，不經過平台 |
| 提貨 | 持有人簽名申請：把凍結權和銷毀權委託給平台並立即凍結，之後不能轉手或掛單。寄出時平台在同一筆交易裡解凍並銷毀，倉庫記錄同步下架。取消申請時平台解凍 |
| 開盲盒（第二階段） | 每個卡包有固定的入庫卡池，開賣前把卡池清單的哈希上鏈承諾；每抽一張用 VRF 隨機數不放回地選卡，同一筆交易裡把該卡的 NFT 鑄給買家 |
| 即時回購（第二階段） | 平台按卡片市值的 70% 付 USDT，NFT 轉回平台錢包 |

### 存貨證明

- 公開的金庫頁（`/vault`）：列出每個編號對應的 NFT 地址、持有人、狀態（在庫、掛單中、提貨中）、入庫日期和最近一次盤點時間；點編號進卡片頁看正反面照片。
- 未銷毀的 NFT 總數必須等於倉庫實物數量：提貨中的卡還在倉庫裡，NFT 凍結但未銷毀；寄出時才銷毀。定期公布盤點結果。
- 平台不持有永久凍結權或永久銷毀權，只有持有人主動申請提貨時才臨時委託給平台。

### 不做

- **不發平台代幣。** 代幣會讓產品被看成炒幣，加重粉絲反感和監管風險；先證明交易本身成立。
- **只給入庫估值 10 USDT 以上的卡鑄造 NFT。** 更便宜的卡留在倉庫內部帳本，避免鑄造和託管成本超過卡價。

## 圖鑑與收藏冊

- 不交易的粉絲也有理由每天來：圖鑑收錄每個卡款（團體 × 專輯 × 成員 × 版本），可以標記「有」和「想要」，旁邊顯示在售數量和最低價；收藏冊照實體卡冊做成 3×3 卡位、雙頁攤開，附收集進度和想要清單。逛圖鑑、記收藏冊不需要登入，登入後收藏冊存進帳號。
- **自由上鏈**：用戶拍下卡片正反面（都必填，背面能看出版本和真偽線索）、選來源、填團體和成員（出處名稱、版本選填），就能鑄造成自述收藏 NFT。來源不只專輯：專輯、預購特典、幸運抽、簽售和視訊簽售、演唱會和見面會周邊、年曆、官方粉絲俱樂部禮包、快閃店、音樂節目和活動、品牌合作、其他。卡款不必在圖鑑裡，圖鑑只提供輸入建議；名稱和圖鑑完全一致時自動關聯卡款。平台不在鑄造時驗真假，上傳假卡也能鑄造。鑄造需要登入。
- 用戶路徑：記錄收藏 → 自由上鏈 → 寄卡入庫鑑定 → 交易。

### 卡片 NFT 的鑑定狀態

所有卡片 NFT 都帶 `verification` 屬性，只有平台能改，持有人改不了：

| 狀態 | 含義 | 怎麼來的 |
|---|---|---|
| `self_reported`（自述） | 持有人自行上鏈，平台未查驗 | 自由上鏈的預設值 |
| `authentic`（真品） | 金庫實物鑑定為正品 | 金庫入庫鑑定通過 |
| `fake`（假卡） | 金庫實物鑑定為假 | 寄到金庫的卡被鑑定為假 |

- **自述收藏 NFT**：鑄造到獨立的「Idolca Collector」Core 集合，用 Bubblegum v2 壓縮 NFT，單張成本可忽略，手續費由平台代付。平台是集合的更新權限持有人，可以用 Bubblegum 的元數據更新指令改寫名稱和元數據 JSON。屬性：團體、成員、來源、出處名稱、版本、圖鑑卡款 ID（有就填）、`custody: self`、`verification`、鑑定日期；正反面照片都放進元數據。
- **鑑定為真**：銷毀自述 NFT，在金庫集合鑄造可交易的金庫 NFT（`custody: vault`、`verification: authentic`）。
- **鑑定為假**：自述 NFT 不銷毀，改寫為 `verification: fake`；名稱加上「[FAKE]」，圖片換成蓋了 FAKE 浮水印的版本，任何外部市場和錢包都看得到。集合帶 PermanentFreezeDelegate 插件，平台可以凍結假卡 NFT，防止它被當作真卡轉賣。標記不可由持有人移除。
- 託管合約只接受金庫集合的資產，自述和假卡 NFT 在鏈上就無法在 Idolca 掛單。
- 目前鑄造是演示模式：紀錄、照片和隨機生成的資產 ID 存進資料庫（`collector_items` 表），鑑定結果透過管理接口 `PATCH /api/admin/items/{id}` 寫入（用 `ADMIN_TOKEN` 保護）。接上 Bubblegum 後，同一個接口同步改寫鏈上元數據。

## 專輯銷量榜單

- Pocamarket 和 KOCA 都沒有專輯銷量榜，這是差異化功能。目前是看板展示（`/charts`）：週榜（本週銷量、累計、在榜週數、排名變化）和初動榜（發行後 7 天銷量），附 Hanteo 和 Circle 的統計口徑說明。
- 數據是樣本：專輯是真實發行的，銷量是示意的。正式版需要授權的榜單數據，按週更新。
- 之後接「代購代拆」：用戶在 Idolca 預購專輯，平台向 Hanteo 加盟店購買並在首爾開封，小卡入庫，專輯計入榜單銷量；上線前要先和 Hanteo 確認這種模式是否計入。

## 盲盒卡包（Mystery Pack）

- 參考 Pocamarket 的 Mystery Pack：低價買一包，有機會抽中高價卡；卡池有限，賣完提前結束；有即時抽卡播報。
- 卡分 SSR、SR、R、N 四級。機率不單獨設定，等於「該級剩餘張數 ÷ 卡池剩餘總數」，所以隨賣出即時變化，頁面公開每級剩餘張數、價值區間和單包期望價值。
- 一次可開 1、5、10 包：撕開卡包，逐張翻卡，SSR 有金色光圈。抽到的卡以 NFT 進錢包，可以留在金庫、上架、即時回購或提貨。
- 卡包合約上線前，開包是演示模式：瀏覽器本地按同樣規則抽卡，不扣款，頁面註明。

## 首頁的 Web3 元素

- 導航列的「連接錢包」按鈕：登入後顯示縮寫地址和 USDT 餘額。
- 所有價格用 USDT 顯示，例如 `1,280 USDT`，滑鼠懸停顯示當地貨幣參考價。
- 卡片標上「On Solana」徽章；點進去能看到 NFT 地址，並連到 Solscan。
- 成交跑馬燈換成鏈上活動流：每筆成交附交易哈希的縮寫。
- 統計區顯示「金庫總值（USDT）」「鏈上持有人數」「24h 鏈上成交」。

## 合規要點

- 盲盒卡包和回購有賭博屬性：機率按卡池剩餘張數即時公開，同時公開單包期望價值；限 18 歲以上，按地區屏蔽；已開的卡包不退款。
- USDT 出入金涉及反洗錢：提現到外部錢包超過一定金額時做 KYC。
- 偶像肖像有 IP 風險：上線後 NFT 和卡片頁只用入庫實物的掃描圖，不拿偶像照片做營銷素材。展示站的樣本卡用 CC BY 授權照片，在 `/credits` 頁署名，不用於廣告投放。

## 卡面圖片

- 沒有實拍圖的卡，卡面由 `src/lib/card-art.ts` 用 canvas 生成佔位圖。
- 卡片資料帶 `image` 時，3D 卡和列表卡改用實拍圖，載入失敗退回佔位圖。入庫後填入正反面掃描圖即可，渲染代碼不用改。
- 樣本卡照片是維基共享資源上 CC BY 授權的偶像照片，放在 `public/cards/samples/`，裁成 55:85；作者和授權記在 `src/lib/sample-credits.json`，由 `/credits` 頁公開署名。
