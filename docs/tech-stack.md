# 技術選型

## 產品定位

K-pop 小卡的鏈上倉儲交易平台：實物入庫鑑定，每張卡在 Solana 上對應一個 NFT；成交時卡留在倉庫，NFT 在鏈上轉移；持有人隨時可以銷毀 NFT，換取實物寄出。價格以 USDT 計價和結算。

用戶有兩種進入方式：
- **加密用戶**：直接連 Phantom、Solflare、Backpack 等錢包。
- **粉絲**：用郵箱或 Google、Apple 登入，系統自動生成一個內嵌錢包，不用懂助記詞和 Gas。

這樣首頁和產品都是 Web3 的，但不把不懂加密的粉絲擋在門外。

## 前端

| 層 | 選擇 | 理由 |
|---|---|---|
| 框架 | Next.js 16（App Router）+ React 19 + TypeScript | 市場頁和卡片頁需要 SSR 和 SEO |
| 樣式 | Tailwind CSS v4 | 深色、光暈這類視覺效果用 CSS 變數集中管理 |
| 3D 卡片 | three.js + React Three Fiber + drei | 首頁主視覺：可拖動旋轉、翻到背面的小卡 |
| 全息效果 | 自寫的 GLSL shader（3D 卡）、CSS 混合模式（列表卡） | 3D 卡只有一張，用 WebGL；列表卡很多，用純 CSS 保證性能 |
| 多語言 | next-intl | 繁中、簡中、英文起步，之後加泰文、印尼文 |

## Web3

| 層 | 選擇 | 理由 |
|---|---|---|
| 鏈 | **Solana** | 卡牌 RWA 的主戰場（約 63% 的代幣化卡牌交易在 Solana）；Magic Eden、Tensor、Jupiter 都能直接交易；手續費不到 1 美分 |
| 登入與錢包 | **Privy** | 郵箱、社群帳號登入自動生成 Solana 內嵌錢包，也支援連接外部錢包；2025 年被 Stripe 收購，之後接法幣入金比較順 |
| 外部錢包 | Solana Wallet Adapter（透過 Privy） | Phantom、Solflare、Backpack |
| 卡片 NFT | **Metaplex Core** | 一張卡一個帳戶，鑄造成本約 0.003 SOL；插件可以存屬性（編號、團體、成員、版本、評級、倉庫位置）、凍結（提貨申請中）、版稅 |
| 計價與結算 | **USDT（SPL）**，同時接受 USDC | 前台一律顯示 USDT，旁邊附當地貨幣的參考價（₩、NT$、HK$、฿） |
| 鏈上程序 | Anchor（Rust） | 自寫一個最小的掛單託管程序：賣家掛單時 NFT 進託管，買家付 USDT 後原子交換，平台抽成在同一筆交易內扣除 |
| 鏈上數據讀取 | Helius RPC + DAS API | 查詢錢包持有的卡、成交紀錄；Webhook 監聽鏈上事件，同步到資料庫 |
| 可驗證隨機數 | Switchboard 或 ORAO VRF | 第二階段的線上拆專輯用，抽卡結果可公開驗證 |

### 鏈上流程

| 動作 | 鏈上發生什麼 |
|---|---|
| 入庫 | 鑑定通過後，平台給寄存人鑄造一個 Core NFT，屬性寫入編號和卡片資料 |
| 掛單、成交 | NFT 進託管程序；買家付 USDT，NFT 和款項在同一筆交易裡交換 |
| 外部交易 | Core NFT 可以在 Magic Eden、Tensor 直接買賣，不經過平台 |
| 提貨 | 持有人申請提貨，NFT 先被凍結；寄出時銷毀，倉庫記錄同步下架 |
| 即時回購（第二階段） | 平台按報價付 USDT，NFT 轉回平台錢包 |

### 存貨證明

- 公開的「金庫」頁面：列出每個編號對應的 NFT 地址、正反面照片、入庫日期、最近一次盤點時間。
- 鏈上 NFT 的總數必須等於倉庫實物數量減去提貨中的數量，定期公布盤點結果。

### 不做

- **不發平台代幣。** 代幣會讓產品被看成炒幣，加重粉絲反感和監管風險；先證明交易本身成立。
- **只給入庫估值 10 USDT 以上的卡鑄造 NFT。** 更便宜的卡留在倉庫內部帳本，避免鑄造和託管成本超過卡價。

## 後端與基礎設施

| 層 | 選擇 | 理由 |
|---|---|---|
| 資料庫 | PostgreSQL（Supabase 或 Neon）+ Drizzle ORM | 卡片資料、倉庫庫存、訂單、物流；鏈上狀態經 Webhook 同步進來，方便查詢 |
| 圖片存儲 | Cloudflare R2 | 卡片正反面高清掃描圖；出口流量免費；NFT 的圖片指向這裡，另存一份到 Arweave 作永久備份 |
| 法幣入金（第二階段） | Privy 內建入金或 MoonPay | 用信用卡買 USDT 直接到內嵌錢包 |
| 部署 | Vercel（前端）、Anchor 程序部署到 Solana 主網 | — |
| 包管理 | npm | 本機已有，不另裝 |

## 首頁的 Web3 元素

- 導航列的「連接錢包」按鈕：登入後顯示縮寫地址和 USDT 餘額。
- 所有價格用 USDT 顯示，例如 `1,280 USDT`，滑鼠懸停顯示當地貨幣參考價。
- 卡片標上「On Solana」徽章；點進去能看到 NFT 地址，並連到 Solscan。
- 成交跑馬燈換成鏈上活動流：每筆成交附交易哈希的縮寫。
- 統計區顯示「金庫總值（USDT）」「鏈上持有人數」「24h 鏈上成交」。

## 合規要點

- 線上拆專輯和回購有賭博屬性：上線前公開抽卡機率，限 18 歲以上，按地區屏蔽。
- USDT 出入金涉及反洗錢：提現到外部錢包超過一定金額時做 KYC。
- 偶像肖像有 IP 風險：NFT 和頁面只用入庫實物的掃描圖，不拿偶像照片做營銷素材。

## 卡面圖片

- 目前的卡面是 `src/lib/card-art.ts` 用 canvas 生成的佔位圖，團體和成員都是虛構的。
- 接入真實卡片後，3D 卡和列表卡改用入庫時拍攝的正反面掃描圖作貼圖，渲染代碼不用改。
