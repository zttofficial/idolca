# 命名

## 推薦：Idolca

- **構詞**：idol（偶像）+ ca（卡）。和圈內的 poca、koca 同一種構詞，粉絲一眼看出是偶像小卡；ca 在中文（卡）、韓文（카드）、日文（カード）、英文（card）裡都讀得出「卡」。
- **讀音**：/aɪˈdɒl.kə/，韓文 아이돌카，三個音節，各語言都沒有難發的音。
- **語感**：直白親切，不帶 coin、chain、fi 這類字眼，粉絲看了不會反感。
- **各語言統一**：所有語言版本都只用 Idolca，不另取中文、日文、韓文名。
- **撞名檢查**：搜尋沒找到同名的 App、品牌或代幣。有人以 Idolca 為姓名，不是商業品牌，不構成衝突。
- **弱點與對策**：
  - 搜尋 "idolca" 會被 idol 本身的結果淹沒：網站和社交帳號統一用 Idolca 拼寫，早期投放關鍵詞廣告。
  - 「偶像 + 卡」接近描述性名稱，文字商標顯著性偏弱：商標連同 logo 圖形一起註冊。

## 備選

| 名字 | 構詞 | 優點 | 缺點 |
|---|---|---|---|
| **HOLOID** | holo（全息）+ idol | 和首頁全息卡視覺呼應；品牌辨識度和商標強度都高 | 不如 Idolca 直白 |
| **Bica** | bias（本命）+ ca | 短，粉絲黑話有圈內認同感 | 葡萄牙語裡是濃縮咖啡 |
| **OnBinder** | on-chain + binder（卡冊） | 產品概念說得最清楚 | 偏功能描述，品牌感弱 |

## 不採用

| 名字 | 原因 |
|---|---|
| PocaVault、Pocafi | 和 Pocamarket（首爾 Infludeo，也做倉儲寄售）太像 |
| Koca 系列 | 台灣已有小卡交易 App KOCA |
| Holca | 北溫哥華已有同名公司 |
| Nika | 常見人名，品牌和代幣撞名可能性高 |
| Ultbias | 圈外人看不懂；已有 Bias Room 用了 bias |
| Pocaverse、Kollect、Choeae | 已有同名或近似的小卡產品 |
