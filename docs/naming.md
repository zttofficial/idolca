# 命名

## 推薦：HOLOID

- **構詞**：holo（全息、閃卡）+ idol（偶像）。一眼看出「偶像的閃卡」，和首頁的全息卡視覺直接呼應。
- **讀音**：/ˈhoʊ.lɔɪd/，英文、中文、韓文（홀로이드）都好唸，兩個音節。
- **語感**：像加密項目的名字（類似 Solana、Phantom 這種構詞），但不帶 coin、chain、fi 這類字眼，粉絲看了不會反感。
- **中文名**：霓卡（霓虹 + 卡），簡短，繁簡同形。
- **撞名檢查**：搜尋沒找到同名的 App、代幣或品牌。最接近的是奧地利的顯微鏡公司 Holloid（兩個 l），行業不同。

## 備選

| 名字 | 構詞 | 優點 | 缺點 |
|---|---|---|---|
| **Ultbias** | ult bias（本命中的本命，粉絲黑話） | 粉絲一看就懂，有圈內認同感 | 圈外人看不懂；已有 Bias Room 用了 bias 這個字 |
| **OnBinder** | on-chain + binder（卡冊） | 「你的鏈上卡冊」，產品概念說得最清楚 | 偏功能描述，品牌感弱 |
| **Pocafi** | poca（小卡）+ fi（金融） | Web3 味最濃 | 容易和 Pocamarket 混淆；「金融」字眼可能引起粉絲反感和監管注意 |

## 不採用

| 名字 | 原因 |
|---|---|
| PocaVault | 和 Pocamarket 太像；vault 偏冷冰冰 |
| Pocaverse、Kollect、Choeae | 已有同名或近似的小卡產品 |

## 定名前要做的事

1. 查網域：`holoid.xyz`、`holoid.io`、`holoid.app`，以及 `.com` 是否可買。
2. 查商標：韓國 KIPRIS、美國 USPTO、WIPO 全球品牌資料庫，類別 9（軟體）、35（線上市場）、36（金融服務）。
3. 佔社交帳號：X、Instagram、TikTok、Discord 伺服器名稱。
4. 定名後，把代碼和文檔裡的 PocaVault 全部替換。
